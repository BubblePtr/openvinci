# 采用 Apache-2.0 而非 AGPL 双许可

曾考虑 AGPL-3.0 + 商业双许可，为将来"图片生成站中间件"形态保留商业授权杠杆；但双许可要求所有外部贡献签 CLA，且与 "OpenVinci" 的开放定位及 Homebrew 分发存在摩擦。本工具的护城河在分发与品牌而非 wrapper 代码本身，故选 Apache-2.0 换取最大采用率与零流程负担。

## Consequences

- 任何人（含竞争者）可将本 CLI 闭源商用或搭建收费服务，无需授权谈判。
- 商业化路径依赖品牌、托管服务与增值组件；未来的中间件组件可作为新代码单独选用限制性协议。
- 在接受外部贡献之前，作者作为唯一版权人仍可为后续版本更换协议；一旦合并外部 PR，更换协议将需要贡献者同意或移除其代码。
